# 🪵 Дровишки — лендинг продажи дров с доставкой

Одностраничный сайт для компании, продающей камерно-сушеные березовые дрова
(влажность ≤ 15%, доставка по Московской области в радиусе 80 км, бесплатная укладка в штабель).

**Живой сайт:** https://artyomr.github.io/FirewoodLanding/

## Возможности

- 7 смысловых блоков: hero → боли → решение → ассортимент → доставка и оплата → оффер с гарантией → контакты
- **Всплывающая форма заказа** (Яндекс Форма) на всех CTA-кнопках, контактных карточках и кнопке в шапке — 16 точек входа, без корзины и бэкенда
- Дизайн: бежевый градиент, стеклянные карточки, sticky-шапка, reveal-анимации при скролле, parallax, 3D-tilt у hero-карточки, hover-зум фотографий
- Полная адаптивность (3 колонки товаров на десктопе → 1 на мобильных), поддержка `prefers-reduced-motion`

## Технологии

Без сборки и зависимостей: **HTML5 + CSS3 + ванильный JS** (шрифт Manrope с Google Fonts).
Открывается двойным кликом по `index.html` — сервер не нужен.

## Структура проекта

```
FirewoodLanding/
├── index.html            # вся разметка (7 секций + шапка, подвал, модалка с формой)
├── styles.css            # все стили: переменные в :root, адаптив в конце файла
├── script.js             # reveal-анимации, parallax, sticky-шапка, логика модалки
├── img/
│   ├── firewood-hero.jpg   # hero: стопка колотых дров крупным планом
│   ├── firewood-birch.jpg  # карточка «Базовый»: колотая берёза
│   ├── crane-truck.webp    # карточка «Оптимальный»: манипулятор с поддонами
│   └── firewood-stack.jpg  # карточка «Для бани»: аккуратная поленница
└── .gitignore
```

## Запуск локально

Вариант 1 — просто открыть `index.html` в браузере.
Вариант 2 — через локальный сервер (например, `python -m http.server 8377`) и открыть
`http://127.0.0.1:8377`.

## Настройка под себя

Перед боевой публикацией замените шаблонные данные:

| Что | Где | Сейчас |
|---|---|---|
| Telegram | поиск по `YYYYYY` | `t.me/YYYYYY`, `@YYYYYY` |
| ВКонтакте | поиск по `YYYYYY` | `vk.com/YYYYYY` |
| Телефон в шапке | `index.html`, шапка | `+7 (XXX) XXX-XX-XX` |
| Цены и объёмы | секция `#assortment` | демо-цены |
| Регион и радиус | hero, подвал | «Московская область, радиус 80 км» |

**Форма заказа** — Яндекс Форма, код встраивания лежит целиком в конце `index.html`
(модалка `#orderModal`). Чтобы подставить свою форму — замените `src` у `<script>` и
`<iframe>` на код вашей формы, остальное (растяжка на всю ширину, открытие/закрытие)
подхватится автоматически.

## Публикация

Сайт размещён на GitHub Pages из ветки `main`. Обновление: внести правки →
`git add .` → `git commit -m "…" ` → `git push` — через 1–2 минуты изменения появятся
на живой странице.
