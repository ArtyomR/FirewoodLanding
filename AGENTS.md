# AGENTS.md — правила для ИИ-агентов

Инструкции для кодинг-агентов (Claude, Copilot, Cursor и др.), работающих с этим репозиторием.

## Что это за проект

Одностраничный лендинг «Дровишки» — продажа камерно-сушеных березовых дров с доставкой.
Чистый **HTML + CSS + JS без сборки, фреймворков и зависимостей**. Любая задача решается
правкой трёх файлов, ничего устанавливать и собирать не нужно.

## Структура

```
index.html   — вся разметка: 7 секций + шапка, подвал, модалка с формой
styles.css   — все стили (переменные в :root, БЭМ-подобный нейминг, адаптив внизу файла)
script.js    — reveal-анимации, parallax, tilt, sticky-шапка, модалка формы (секция 4)
img/         — 4 фотографии (см. «Фотографии и лицензии»)
.gitignore   — скриншоты 2026-*.png и мусор ОС в репозиторий не попадают
```

Секции `index.html`: `#hero` → `#pains` → `#solution` → `#assortment` → `#delivery` → `#offer` → `#contacts`.

## Запуск локально

Сервер не обязателен: откройте `index.html` двойным кликом. Для проверки через http:
`python -m http.server 8377` или `npx serve` в корне проекта.

## Инварианты — не ломать

1. **Код Яндекс Формы в `index.html` (блок `#orderModal`) должен оставаться дословным**:
   `<script src="https://forms.yandex.ru/_static/embed.js"></script><iframe src="https://forms.yandex.ru/u/6afb127cb9e5ca882335b0e7?iframe=1" frameborder="0" name="ya-form-6afb127cb9e5ca882335b0e7" width="650"></iframe>`
   Не менять `width="650"` и не удалять `<script>` — ширину растягивает CSS-оверрайд
   `.modal__window iframe { width: 100% !important; }`.
2. **Открытие формы — только через атрибут `data-open-form`.** JS (секция 4 `script.js`)
   вешает `preventDefault` и открывает модалку. У кнопки всегда остаётся настоящий `href` —
   это фолбэк без JS. Закрытие: `[data-close-form]` (оверлей + крестик) и Escape.
3. **Плейсхолдеры `YYYYYY`** — шаблонные контакты (`t.me/YYYYYY`, `vk.com/YYYYYY`,
   `@YYYYYY`). При вводе реальных данных менять только их, механику не трогать.
4. **Без бэкенда**: никаких Google Таблиц, скриптов Code.js, корзины, серверных форм.
   Заявки идут только через Яндекс Форму.
5. **Sticky-шапка**: у `html`/`body` есть `overflow-x: clip` — новые `overflow`-правки
   на предках шапки её сломают. Проверяйте sticky после таких изменений.
6. **Анимации уважают `prefers-reduced-motion`** — новые эффекты добавляйте так, чтобы
   при reduced-motion они отключались (см. конец `styles.css`).

## Фотографии и лицензии

Фото в `img/` — свободные лицензии (Wikimedia Commons / Flickr), атрибуция — HTML-комментарием
перед `</body>`. `crane-truck.webp` предоставлен заказчиком (источник drova-krasnoyar.ru,
права проверить перед коммерческой публикацией). При замене фото обновите атрибуцию
и не переименовывайте файлы без правки всех `src` и альтов.

## Стиль кода

- CSS: переменные из `:root` (`--orange`, `--radius`…), классы вида `.блок__элемент`,
  медиазапросы — в блоке «Адаптив» в конце файла (1020px, 640px).
- JS: один IIFE, `"use strict"`, ES5-совместимый синтаксис, комментарии-секции
  `/* ---------- N. Название ---------- */`.
- Тексты на русском, тон — как в существующих секциях (честно, без рекламы).

## Проверка изменений

1. Открыть страницу в браузере, консоль — без ошибок.
2. Кликнуть любую кнопку с `data-open-form`: модалка открылась, форма загрузилась,
   iframe на всю ширину окна; закрыть крестиком/оверлеем/Escape.
3. Сузить окно до ~380px: сетки в одну колонку, форма не вылезает за экран.
4. Сделать скриншоты для себя в корень проекта можно, но они не коммитятся (см. `.gitignore`).

## Публикация

Сайт живёт на GitHub Pages из ветки `main`: правки публикуются автоматически после
`git push` (сборка ~1–2 минуты). Коммит-сообщения — короткие, по-русски, без префиксов.
